# Hypothesis Lab reports

Los manifests, resúmenes JSON e informes Markdown pequeños se generan aquí. Todos los artefactos deben incluir `research_only: true` y el aviso **Research only - No señal - No bot**. La base SQLite operacional y los candidatos completos viven en `data/hypothesis_lab/`, que está gitignored.

Estos resultados usan `recycled_research_data`; no son holdout virgen y nunca habilitan selección automática, señal, bot ni promoción live.
