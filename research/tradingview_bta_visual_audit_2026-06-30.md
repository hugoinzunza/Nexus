## Inventario de elementos visuales

| Elemento | Cómo aparece | Lectura operativa probable |
| --- | --- | --- |
| Premium POI | Caja gris alta, a veces con texto `Premium POI` o `Premium POI X Confirmación` | Zona de venta o rechazo dentro de premium del rango |
| Discount POI | Caja gris baja, texto `Discount POI` o `Discount POI x confirmación` | Zona de compra o reacción dentro de discount del rango |
| CDC | Línea horizontal roja/rosada con texto `CDC` | Nivel de cambio de carácter/confirmación; perderlo o recuperarlo valida dirección |
| Alto Referencial | Línea horizontal negra con texto `Alto Referencial (Resistencia)` | Liquidez/techo de referencia; objetivo o invalidación |
| Strong High | Línea negra con texto `Strong High (Nivel De Resistencia)` | Máximo defendido o resistencia estructural |
| Checks verdes | Icono check sobre una zona | Zona que reaccionó/confirmó correctamente |
| Franjas azules verticales | Rectángulos verticales translúcidos | Ventanas de validación/reacción/desplazamiento |
| Zonas celestes | Trazos gruesos horizontales manuales | Bloques de liquidez, soportes/resistencias o targets parciales |
| Círculos celestes | Puntos en swings | Pivotes/fractales usados para estructura |
| Zigzag morado | Trazado entre pivotes | Estructura swing, posible lectura de legs y targets |
| Caja naranja | Rectángulo de rango/objetivo | Área de llegada, distribución o rango de toma de liquidez |
| Máximo/Mínimo naranja | Etiquetas automáticas en extremos | Extremos operativos del rango visible |

## Reglas inferidas con más detalle

1. Definir rango operativo: máximo/mínimo visible o swing relevante.
2. Separar premium y discount del rango.
3. Marcar POIs en premium/discount, no cualquier OB.
4. Esperar CDC o confirmación; si el CDC se pierde, cambia el rol de la zona.
5. Validar con reacción: checks verdes aparecen donde el precio respeta la zona.
6. Usar `Alto Referencial`, `Strong High` y mínimos marcados como liquidez/objetivo.
7. Cuando hay desplazamiento fuerte, el retroceso a POI se lee como continuación.
8. La capa de zigzag/pivotes sirve para no operar zonas sueltas: define qué swing manda.

## Conclusión

La estrategia visible del profe no es una sola señal. Es una lectura jerárquica: estructura swing -> rango -> premium/discount -> POI -> CDC -> reacción -> liquidez objetivo. El estudio cuantitativo inicial sirve como control, pero para comparar de verdad con Nexux hay que agregar una capa visual/estructural que replique estos objetos del chart y sus estados.
