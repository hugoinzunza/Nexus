Conecta tu Binance

Tu Diario es privado: muestra solo tu cuenta. Para verlo, conecta una API key de Binance de solo lectura (sin permiso de retiro). La llave se guarda cifrada; solo el motor (VPS) la usa para leer, esta web nunca la ve en claro.

  1. En Binance: Account → API Management → Create API (System generated).
  2. Permisos: deja Enable Reading (y Enable Futures si operas futuros). No habilites retiros ni transferencias.
  3. Copia la API Key y la Secret Key y pégalas aquí.

Al conectar aceptas los Términos y la Política de Privacidad. Solo se aceptan llaves de solo lectura.

Esperando datos del colector

El Diario muestra los datos que envía el colector del VPS. Binance bloquea los servidores de Railway por ubicación, así que la lectura se hace desde un VPS (Alemania) y se ingiere acá.

Todavía no llegó ningún envío. Cuando el colector corra (cada ~5 min vía systemd), tus estadísticas aparecerán aquí.
